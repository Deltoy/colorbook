# 배색사전

와다 산조 『배색사전(A Dictionary of Color Combinations)』의 159색·348배색을 폰에서 보는 개인용 앱. 퍼스널컬러 10톤 중 내 톤을 골라 어울리는 색 표시(fit.js), 코디 매칭, 오늘 뭐 입지(매일 추천), 사용법, 내 얼굴로 보기(사진은 기기에만 저장), 액세서리 추천.
색 데이터: [mattdesl/dictionary-of-colour-combinations](https://github.com/mattdesl/dictionary-of-colour-combinations) (MIT). `node build.js` 로 data.js 재생성.
